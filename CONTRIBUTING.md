# Contributing

Baldanders accepts issues, not pull requests. Bug reports and missed detections are the most useful thing you can send.

## Reporting a bug or a missed detection

[Open an issue](https://github.com/Nahuel990/Baldanders/issues/new/choose) and include:

- Your version (`baldanders --version`) and the provider you used (`-p claude`, `-p chatgpt`, ...).
- A made-up example that reproduces the problem.
- For detection problems, the "SENT TO AI" box from a run with `-v`.

If personal data reached the AI despite scrubbing, [report it privately](https://github.com/Nahuel990/Baldanders/security/advisories/new) instead of in a public issue.

## Never use real personal data

Not in issues or screenshots. Use made-up names and the documented example numbers from [python-stdnum](https://arthurdejong.org/python-stdnum/), which pass checksums but belong to no one.
